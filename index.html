04

テンプレートの作り方

ここが実装の中でいちばん重要で、いちばん簡単な部分です。 既存の見本をGoogleドキュメントにして、企業ごとに変わる箇所を {{ }} で囲むだけです。

手順

  1. 既存の見積書・成果シミュレーション・業務設計書を、Googleドキュメントとして保存します
  2. 企業ごとに変わる箇所を {{企業名}} のように置き換えます
  3. 3つのドキュメントIDを、設定ファイルの TEMPLATES に貼ります

置き換えの例

【変更前】
株式会社サンプル製作所 御中
合計金額：2,800,000円（税別）
削減見込：月48時間

【変更後】
{{企業名}} 御中
合計金額：{{合計金額}}
削減見込：{{削減時間}}
キーの名前は自由です

日本語でも英語でも構いません。コードは {{ }} の中を読んで、 そのままAIへ渡すキーとして使います。 「{{今期の課題仮説}}」のように長い名前にすると、AIが何を書くべきか分かりやすくなり、精度が上がります。

表・見出し・書式はそのままで構いません

置換は文字だけを対象にします。表組み・フォント・ロゴ・改ページは一切触りません。 そのため、見本の体裁がそのまま生成物の体裁になります。

05

実装手順

STEP 1　Apps Scriptで新しいプロジェクトを作り、名前を「営業支援コンソール」にします。

経費自動化とは別プロジェクトを推奨します

設定値の名前は 営業支援設定／経費設定 と分けてあり、共通の関数名も重ならないようにしてあります。同名の衝突は解消済みですが、権限とトリガーの管理を分けるため、プロジェクトは分けることをおすすめします。

STEP 2　第6章の5つの .gs を、同じ名前でファイル追加して貼り付けます。

STEP 3　画面だけはHTMLファイルとして追加します。

ファイルの ＋→HTML→名前は「画面」

.html は自動で付きます。名前を変える場合は、メインの createHtmlOutputFromFile('画面') も合わせて直してください。

STEP 4　「設定」の 営業支援設定 を、第3章で用意したIDに書き換えます。

STEP 5　スクリプトプロパティに CLAUDE_API_KEY を登録します。

歯車→プロジェクトの設定→スクリプト プロパティ

STEP 6　第7章の順に動作確認します。

STEP 7　問題なければ、Webアプリとしてデプロイします。

デプロイ→新しいデプロイ→種類：ウェブアプリ
設定項目選ぶもの理由
次のユーザーとして実行自分台帳とドライブへのアクセスを1つに集約するため
アクセスできるユーザー組織内の全員営業メンバーが使う場合。代表のみなら「自分のみ」
「全員（匿名ユーザーを含む）」は選ばないでください

URLを知っていれば社外の誰でも開けてしまい、企業データが外部から見える状態になります。

/**
 * 営業支援コンソール｜企業データ台帳
 * ------------------------------------------------------------------
 * CSVの取り込みと、企業データ台帳の読み書きを担当します。
 *
 * ★API契約が決まったら、差し替えるのはこのファイルだけです。
 * 　importFromCsv_() と同じ形（COMPANY_HEADERS の並びの配列）を返す
 * 　importFromApi_() を書けば、他のファイルは一切変更が要りません。
 * ------------------------------------------------------------------
 */

/** 台帳シートを取得（無ければ見出し付きで作成） */
function getCompanySheet_() {
  return getSheet_(営業支援設定.SHEET_COMPANIES, COMPANY_HEADERS);
}

/** ブック内のシートを取得（無ければ見出し付きで作成） */
function getSheet_(name, headers) {
  const ss = SpreadsheetApp.openById(営業支援設定.SHEET_ID);
  let sh = ss.getSheetByName(name);
  if (!sh) {
    sh = ss.insertSheet(name);
    sh.appendRow(headers);
    sh.getRange(1, 1, 1, headers.length).setFontWeight('bold');
    sh.setFrozenRows(1);
  }
  return sh;
}

/** 見出し行から「列名 → 列番号（0始まり）」を作る */
function columnIndex_(headerRow) {
  const map = {};
  headerRow.forEach(function (h, i) {
    const key = String(h || '').normalize('NFKC').trim();
    if (key && map[key] === undefined) map[key] = i;
  });
  return map;
}


// --------------------------- 読み取り ---------------------------

/**
 * 台帳の全企業を読む
 * 列は位置ではなく見出し名で探すため、列を足しても並べ替えても壊れません。
 */
function readCompanies_() {
  const sh = getCompanySheet_();
  const values = sh.getDataRange().getValues();
  if (values.length < 2) return [];

  const col = columnIndex_(values[0]);
  const out = [];

  for (let i = 1; i < values.length; i++) {
    const row = values[i];
    const c = {};
    COMPANY_HEADERS.forEach(function (h) {
      c[h] = col[h] === undefined ? '' : row[col[h]];
    });
    if (!String(c['企業名'] || '').trim()) continue;
    c._row = i + 1;                       // 更新時に使う行番号
    c._missing = missingFields_(c);
    out.push(c);
  }
  return out;
}

/** 企業名で1社を探す（表記ゆれを吸収して照合） */
function findCompany_(name) {
  const key = normName_(name);
  return readCompanies_().filter(function (c) {
    return normName_(c['企業名']) === key;
  })[0] || null;
}

/** 必須項目のうち、空になっているものを返す */
function missingFields_(c) {
  return REQUIRED_FIELDS.filter(function (f) {
    const v = c[f];
    return v === '' || v === null || v === undefined || v === 0;
  });
}

/** 企業名の照合キー（全角半角・空白・法人格の表記ゆれを吸収） */
function normName_(v) {
  return String(v || '')
    .normalize('NFKC')
    .replace(/[\s　]/g, '')
    .replace(/株式会社|有限会社|合同会社|\(株\)|\(有\)/g, '')
    .toLowerCase();
}

/**
 * CSVを台帳へ取り込む
 * ・1行目は見出し。COMPANY_HEADERS と同じ日本語名でも、英語列名でも受け付けます
 * ・既に台帳にある企業は上書き更新します（キーは企業名）
 *
 * @param {string} csvText アップロードされたCSVの中身
 * @return {Object} { added, updated, skipped, problems: [] }
 */
function importFromCsv_(csvText) {
  const rows = Utilities.parseCsv(csvText);
  if (!rows || rows.length < 2) {
    return { added: 0, updated: 0, skipped: 0, problems: ['データ行がありません'] };
  }

  const col = csvHeaderIndex_(rows[0]);
  if (col['企業名'] === undefined) {
    return { added: 0, updated: 0, skipped: 0,
             problems: ['「企業名」にあたる列が見つかりません（company_name でも可）'] };
  }

  const sh = getCompanySheet_();
  const existing = {};
  readCompanies_().forEach(function (c) { existing[normName_(c['企業名'])] = c._row; });

  const today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy-MM-dd');
  const problems = [];
  const appends = [];
  let added = 0, updated = 0, skipped = 0;

  for (let i = 1; i < rows.length; i++) {
    const r = rows[i];
    if (r.join('').trim() === '') continue;

    const rec = COMPANY_HEADERS.map(function (h) {
      if (h === '更新日') return today;
      return col[h] === undefined ? '' : String(r[col[h]] || '').trim();
    });

    const name = rec[COMPANY_HEADERS.indexOf('企業名')];
    if (!name) { skipped++; problems.push((i + 1) + '行目：企業名が空のため取り込みませんでした'); continue; }

    // 必須項目の欠けは記録するが、取り込み自体は行う（画面で補完できるため）
    const asObj = {};
    COMPANY_HEADERS.forEach(function (h, idx) { asObj[h] = rec[idx]; });
    const miss = missingFields_(asObj);
    if (miss.length) problems.push((i + 1) + '行目「' + name + '」：' + miss.join('・') + ' が空欄です');

    const at = existing[normName_(name)];
    if (at) {
      sh.getRange(at, 1, 1, COMPANY_HEADERS.length).setValues([rec]);
      updated++;
    } else {
      appends.push(rec);
      added++;
    }
  }

  if (appends.length) {
    sh.getRange(sh.getLastRow() + 1, 1, appends.length, COMPANY_HEADERS.length).setValues(appends);
  }

  Logger.log('取り込み：新規 %s / 更新 %s / 見送り %s', added, updated, skipped);
  return { added: added, updated: updated, skipped: skipped, problems: problems };
}

/**
 * CSVの見出しを COMPANY_HEADERS に対応づける
 * 日本語見出しでも、英語見出し（company_name 等）でも受け付けます。
 */
const CSV_ALIASES = {
  '企業名': ['company_name', 'company', 'name', '会社名', '商号'],
  '業種': ['industry', 'sector', '業界'],
  '従業員数': ['employees', 'employee_count', '従業員'],
  '売上高': ['revenue', 'sales', '売上'],
  '事業内容': ['business_desc', 'business', 'description', '事業'],
  '所在地': ['address', 'location', '住所'],
  '代表者': ['representative', 'ceo', '代表'],
  '設立年': ['established', 'founded', '設立'],
  '決算月': ['fiscal_month', 'fiscal', '決算'],
  '利益': ['profit', 'income'],
  '法人番号': ['corporate_number', 'corp_no'],
  '備考': ['note', 'notes', 'memo', 'remarks'],
};

function csvHeaderIndex_(headerRow) {
  const raw = headerRow.map(function (h) {
    return String(h || '').normalize('NFKC').replace(/[\s　]/g, '').toLowerCase();
  });
  const map = {};
  COMPANY_HEADERS.forEach(function (h) {
    const cands = [h].concat(CSV_ALIASES[h] || []).map(function (x) {
      return String(x).normalize('NFKC').replace(/[\s　]/g, '').toLowerCase();
    });
    for (let i = 0; i < raw.length; i++) {
      if (cands.indexOf(raw[i]) >= 0) { map[h] = i; break; }
    }
  });
  return map;
}

テンプレートの差し込み箇所を読み、Claudeに値を作らせる

Apps Scriptでのファイル名：生成
/**
 * 営業支援コンソール｜資料の生成
 * ------------------------------------------------------------------
 * テンプレート（Googleドキュメント）から差し込み箇所を読み取り、
 * その箇所に入る値だけを Claude に作らせます。
 *
 * ★体裁はテンプレートが保証し、AIは中身だけを担当します。
 * 　これにより、生成のたびにレイアウトが崩れることがありません。
 * ------------------------------------------------------------------
 */

/**
 * テンプレートから差し込み箇所を洗い出す
 * ドキュメント本文の {{ ... }} をすべて拾います。
 *
 * @return {string[]} 例：['企業名','業種','合計金額','前提条件']
 */
function extractPlaceholders_(docId) {
  const text = DocumentApp.openById(docId).getBody().getText();
  const found = text.match(/\{\{\s*[^}]+\s*\}\}/g) || [];
  const keys = found.map(function (t) {
    return t.replace(/[{}]/g, '').trim();
  });
  // 重複を除く
  return keys.filter(function (k, i) { return k && keys.indexOf(k) === i; });
}


/**
 * 1フォーマット分の差し込み値を生成する
 *
 * @param {Object} company 台帳から読んだ企業データ
 * @param {string} formatKey 'quote' | 'sim' | 'design'
 * @param {string} extra 追加指示（再生成時のみ。無ければ空文字）
 * @return {Object} { 差し込みキー: 値 } の形
 */
function generateValues_(company, formatKey, extra) {
  const tpl = 営業支援設定.TEMPLATES[formatKey];
  if (!tpl) throw new Error('未知のフォーマットです：' + formatKey);

  const keys = extractPlaceholders_(tpl.docId);
  if (keys.length === 0) {
    throw new Error('テンプレート「' + tpl.label + '」に {{ }} の差し込み箇所が見つかりません');
  }

  const prompt = buildPrompt_(company, tpl.label, keys, extra);
  const raw = callClaude_(prompt);
  const parsed = parseJson_(raw);

  // テンプレートにある差し込み箇所を必ず全部埋める（欠けは空文字にして事故を防ぐ）
  const values = {};
  keys.forEach(function (k) {
    values[k] = (parsed && parsed[k] !== undefined && parsed[k] !== null) ? String(parsed[k]) : '';
  });
  return values;
}


/** Claudeへ渡す指示文を組み立てる */
function buildPrompt_(company, formatLabel, keys, extra) {
  const facts = COMPANY_HEADERS.filter(function (h) { return h !== '更新日'; })
    .map(function (h) { return h + '：' + (company[h] === '' ? '（未登録）' : company[h]); })
    .join('\n')
    .slice(0, 営業支援設定.MAX_INPUT_CHARS);

  return [
    'あなたは法人向けの業務改善を提案するコンサルタントです。',
    '下記の企業データをもとに、「' + formatLabel + '」の差し込み箇所を埋めてください。',
    '',
    '【守っていただきたいこと】',
    '- 企業データに書かれていない事実を、推測して断定しないこと',
    '- 根拠が無い数値は出さないこと。試算する場合は前提を必ず併記すること',
    '- 「（未登録）」の項目は、その旨がわかる表現にするか、触れないこと',
    '- 出力はJSONのみ。説明文やマークダウンの装飾は付けないこと',
    '',
    '【企業データ】',
    facts,
    '',
    extra ? '【今回の追加指示】\n' + extra + '\n' : '',
    '【出力するJSONのキー】',
    '次のキーをすべて含むJSONを1つだけ返してください。値はすべて文字列にしてください。',
    JSON.stringify(keys, null, 0),
  ].join('\n');
}


/** Claude API を呼ぶ */
function callClaude_(prompt) {
  const key = PropertiesService.getScriptProperties().getProperty('CLAUDE_API_KEY');
  if (!key) throw new Error('スクリプトプロパティ CLAUDE_API_KEY が未設定です');

  const res = UrlFetchApp.fetch('https://api.anthropic.com/v1/messages', {
    method: 'post',
    contentType: 'application/json',
    headers: { 'x-api-key': key, 'anthropic-version': '2023-06-01' },
    payload: JSON.stringify({
      model: 営業支援設定.MODEL,
      max_tokens: 営業支援設定.MAX_TOKENS,
      messages: [{ role: 'user', content: prompt }],
    }),
    muteHttpExceptions: true,
  });

  const code = res.getResponseCode();
  if (code < 200 || code >= 300) {
    throw new Error('Claude APIエラー（' + code + '）：' + res.getContentText().slice(0, 300));
  }

  const json = JSON.parse(res.getContentText());
  const blocks = json.content || [];
  const text = blocks.filter(function (b) { return b.type === 'text'; })
                     .map(function (b) { return b.text; }).join('');
  if (!text) throw new Error('Claudeからの応答が空でした');
  return text;
}


/**
 * 応答からJSONを取り出す
 * 前後に説明文が付いた場合でも、最初の { から最後の } までを拾います。
 */
function parseJson_(text) {
  try {
    return JSON.parse(text);
  } catch (e) {
    const s = text.indexOf('{'), t = text.lastIndexOf('}');
    if (s >= 0 && t > s) {
      try { return JSON.parse(text.slice(s, t + 1)); } catch (e2) { /* 次へ */ }
    }
    Logger.log('JSONとして読めませんでした：' + text.slice(0, 200));
    return null;
  }
}

/**
 * 営業支援コンソール｜生成物の出力
 * ------------------------------------------------------------------
 * テンプレートを複製し、{{ }} を差し込み値に置き換えて、
 * クライアント別フォルダへ保存します。
 *
 * ★元のテンプレートは複製元として使うだけで、書き換えません。
 * ------------------------------------------------------------------
 */

/**
 * 1フォーマット分のドキュメントを作る
 *
 * @param {Object} company 企業データ
 * @param {string} formatKey 'quote' | 'sim' | 'design'
 * @param {Object} values generateValues_() の戻り値
 * @return {Object} { name, url, id }
 */
function renderDocument_(company, formatKey, values) {
  const tpl = 営業支援設定.TEMPLATES[formatKey];
  const folder = getClientFolder_(company['企業名']);
  const stamp = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyyMMdd');
  const name = [stamp, company['企業名'], tpl.label].join('_');

  // テンプレートを複製（テンプレート自体は変更しない）
  const copy = DriveApp.getFileById(tpl.docId).makeCopy(name, folder);
  const doc = DocumentApp.openById(copy.getId());
  const body = doc.getBody();

  // {{キー}} を値に置き換える
  Object.keys(values).forEach(function (k) {
    body.replaceText(placeholderPattern_(k), escapeForReplace_(values[k]));
  });

  // 埋め残しがあれば空文字にして、{{ }} が残ったまま顧客に出ないようにする
  body.replaceText('\\{\\{[^}]*\\}\\}', '');

  doc.saveAndClose();
  return { name: name, url: copy.getUrl(), id: copy.getId() };
}


/** {{キー}} を探す正規表現（記号が入っていても壊れないようにエスケープ） */
function placeholderPattern_(key) {
  const esc = String(key).replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  return '\\{\\{\\s*' + esc + '\\s*\\}\\}';
}

/** 置換文字列に含まれると誤動作する記号を無害化する */
function escapeForReplace_(v) {
  return String(v === undefined || v === null ? '' : v).replace(/\$/g, '$$$$');
}


/**
 * クライアント別フォルダを取得（無ければ作成）
 * 保存先： 営業支援設定.FOLDER_OUT / 企業名 /
 */
function getClientFolder_(companyName) {
  const parent = DriveApp.getFolderById(営業支援設定.FOLDER_OUT);
  const safe = String(companyName).replace(/[\/\\:*?"<>|]/g, '_').trim();
  const it = parent.getFoldersByName(safe);
  return it.hasNext() ? it.next() : parent.createFolder(safe);
}

/** 生成履歴を新しい順に読む（画面の③タブで使用） */
function readHistory_(limit) {
  const sh = getSheet_(営業支援設定.SHEET_HISTORY, HISTORY_HEADERS);
  const values = sh.getDataRange().getValues();
  if (values.length < 2) return [];

  const col = columnIndex_(values[0]);
  const rows = [];
  for (let i = values.length - 1; i >= 1; i--) {
    const r = values[i];
    rows.push({
      at:      String(r[col['実行日時']] || ''),
      user:    String(r[col['実行者']] || ''),
      company: String(r[col['企業名']] || ''),
      formats: String(r[col['生成物']] || ''),
      links:   String(r[col['保存先']] || ''),
      status:  String(r[col['状態']] || ''),
    });
    if (limit && rows.length >= limit) break;
  }
  return rows;
}

 *
 * @param {string} name 企業名
 * @param {Object} valuesByFormat api_generate の戻り値 values（画面で修正されている場合あり）
 */
function api_save(name, valuesByFormat) {
  const c = findCompany_(name);
  if (!c) throw new Error('企業が見つかりません：' + name);

  const keys = Object.keys(valuesByFormat || {});
  if (!keys.length) throw new Error('保存する内容がありません');

  const results = [];
  try {
    keys.forEach(function (k) {
      results.push(renderDocument_(c, k, valuesByFormat[k]));
    });
    logHistory_(c, keys, results, '正常', '');
    return { saved: results, folder: getClientFolder_(c['企業名']).getUrl() };
  } catch (e) {
    logHistory_(c, keys, results, 'エラー', String(e));
    throw e;
  }
}

#実行する関数確認できること事前に必要なもの

注意点と未実装

設計上の注意

項目内容
保存は必ず人の確認後生成しただけでは保存されません。画面で値を直してから保存する流れです。見積書は金額が入るため、この順序は変えないことをおすすめします
埋め残しは空文字にするAIが値を返さなかった箇所は空にします。{{ }} が残ったまま顧客に出ることを防ぐためです
テンプレートは複製元元のテンプレートは書き換えません。誤って壊すことがない作りです
必須項目が欠けても止めない警告は出しますが生成はできます。データが揃うまで使えないより、精度が落ちても使えるほうが実務に合うためです
実行時間3フォーマットで30〜60秒程度。Apps Scriptの上限6分には十分収まります

使用モデルについて

設定の既定は claude-opus-5 です。 要件定義の費用試算（月2,600円）は claude-sonnet-5 を前提にしているため、 費用を優先する場合は設定を書き換えてください。3フォーマット×100件の想定なら、 どちらでも月数千円の範囲です。
